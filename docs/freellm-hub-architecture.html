FreeLLM Hub 系统架构

本地优先的免费大模型聚合平台

核心组件

  • • Scheduler: 智能调度、候选过滤、评分选优
  • • Rate Limiter: 令牌桶限流 + 进程内熔断

数据层

  • • 日志保留策略: 自动清理过期记录

API 与网关

  • • OpenAI 兼容: /v1/chat/completions (流式)
  • • 模型列表: /v1/models
  • • 健康检查: /health
  • • REST API: 端口 3000 (管理) / 3001 (网关)
